# Logo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the hockey emoji (&#127953;) with a proper SVG logo across all touchpoints (nav bar, landing page, favicon, emails).

**Architecture:** Create 5 SVG files in `app/public/logo/`. Each variant is derived from the approved "Combined v2" design — a goal net frame with puck in the top left corner, green glow, and diagonal speed lines. SVGs are referenced directly in components and inlined in emails.

**Tech Stack:** SVG, Next.js Image/static files, inline HTML for emails

---

## File Structure

| File | Purpose |
|------|---------|
| `app/public/logo/logo-horizontal.svg` | Nav bar: icon mark left + text right |
| `app/public/logo/logo-icon-round.svg` | Favicon + PWA icon (circular border) |
| `app/public/logo/logo-icon-square.svg` | App icon (rounded square border) |
| `app/public/logo/logo-hero.svg` | Landing page: large centered logo |
| `app/public/logo/logo-email.svg` | Email header: inline-safe SVG |
| `app/src/components/Navigation.tsx` | Replace emoji with horizontal logo |
| `app/src/app/page.tsx` | Replace emoji with hero logo on landing |
| `app/src/lib/email-templates.ts` | Replace emoji with email SVG logo |
| `app/src/app/layout.tsx` | Add favicon metadata |
